# LLM Obsidian 2.6.3: documentation coverage and authority matrix

## Source-of-truth manifest

| Domain | Authoritative source | Handbook responsibility | Drift check |
|---|---|---|---|
| Agent/vault operating rules | `AGENTS.md`, `CLAUDE.md` | Link and teach the supported route; never redefine write, Git, failure-repair, or lifecycle rules | Required source names + independent review |
| PipelineSpec fields | `schemas/pipeline-spec-v1.schema.json` | Complete Russian field reference and compiled example | Strict parser/compiler test |
| Built-in primitives/skills | `scripts/harness/pipeline_builtins.py` | Explain current immutable catalog | Pipeline compile test |
| Custom policy/checks | `scripts/harness/custom_pipeline_contracts.py` | Explain ceiling, approval, fail-closed rejection | Custom pipeline suite |
| Task/session/review/reap | `docs/task-sessions.md`, `docs/unattended-pipeline-operations.md`, lifecycle skills | Task-oriented route and recovery | Harness focused/full suites |
| Runtime capability/fallback | `docs/runtime-capabilities.md` | Cross-runtime matrix and explicit fallback | Adapter and runtime tests |
| Model routing | `config/model-routing.toml`, `docs/model-routing.md` | Explain resolver/drift without hardcoding defaults | Model routing/literal lint |
| Vault writer/retrieval | `scripts/vault-write.py`, `scripts/retrieve.py`, `AGENTS.md` | Safe save/query/operator journeys | Vault and retrieval tests |
| Document/research isolation | `docs/document-ingestion.md`, research workflow/tests | Ingest/protected research route | Normalization/isolation suites |
| Developer commands | `Makefile`, scripts `--help` | Cheap-first command reference | Exact command runs |
| Skill inventory | `skills/*/SKILL.md`, generated marketplaces | Exactly one row per installed skill and both invocation forms | Dynamic inventory gate |

The handbook is subordinate to these carriers. A prose sentence never silently
overrides an operating contract; version-sensitive facts point back to one
maintained authority.
