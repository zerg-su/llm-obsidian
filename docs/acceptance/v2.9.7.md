## Corrections established by live evidence

The opening helper now joins the runtime-scoped terminal handle to
`session.tabs.list` agent-status evidence and independently verifies the full ID.
Launch envelopes may omit resume facts; missing live proof still blocks success.
A bounded read-only wait allows startup hooks to publish that identity.

Native chat closure uses the installed `CloseTab` schema and exact tab inventory,
not GUI automation or title changes. After a lost close response, only a read is
performed. A selected tab's absence and retained neighbors prove completion.

The generic daily guide omitted already installed documentation/metrics skills;
that real validation blocker was fixed through the vault writer before retry.

## Compatibility limits

Internal APIs require the selected installation's schemas and matching host/CLI
versions. Unsupported layouts or missing identity metadata fail explicitly.
Opening currently uses terminal surfaces. A future documented public resume
command takes precedence. Stale/unknown launch receipts require read-only
reconciliation; a second blind mutation is prohibited.
