# LLM Obsidian 2.6.5 transport smoke

## Question

Can one cheap probe cover the finite transport shapes that differ materially,
without adding another lifecycle owner or spending a model call on every test?

## Disposable evidence

`/private/tmp/llm-obsidian-transport-smoke.py`.

- On the current candidate it passed seven contracts: compact Codex pointer,
  unchanged Claude prompt, interactive deferred input, ephemeral prompt argv,
  Codex update `Skip`, current callback wake, and purpose-bound callback wake.
- Against historical parent `5eebf8c`, the same bytes passed the first five
  contracts and failed exactly at `current callback wake is executable without
  legacy plan`. That parent still appended synthetic scope as `current --plan`.
- Two real Simple skill reviews then exercised the live paths. Codex/Sol
  callback `review-b9531441b5bfc9a8b9bdc270` approved; Claude/Opus callback
  `review-0112e01b935359d6a860cf0c` approved with one minor test-quality finding.

  command repair.
- Three earlier disposable Codex workspaces proved that a multiline `cmux send`
  is one transport send but expands the editor, while a one-line digest-bound
  pointer is read successfully. All three workspaces were closed by exact ID.

## Promotion decision

`prototypes/runtime-transport-smoke.py` is a manual preflight for changes to
provider input, native prompt handling, or current-review callback compilation.
Its default mode imports existing production policy seams and owns no state,
process, cmux surface, callback, retry, cleanup, or release transition. The
opt-in `--live-cmux` mode temporarily owns one uniquely named workspace and
only its exact surfaces: an extra tab, a right split and a left split. A final
tree/list check proves that targeted surface cleanup preserves the anchor and
that workspace cleanup leaves no tail. It is deliberately not another Harness
and is not added to every normal test run.

Run it from the repository root:

```bash
python3 prototypes/runtime-transport-smoke.py --repo "$PWD"
python3 prototypes/runtime-transport-smoke.py --repo "$PWD" --live-cmux
```

The live CMUX probe passed against the release candidate: three panes were
observed inside the isolated workspace; the two split panes collapsed back to
the original anchor; the workspace and every added surface were absent after
cleanup. The two unrelated pre-existing workspaces were unchanged.

The focused production regressions remain authoritative:
`tests/harness/test_runtime_sessions.py`,
`tests/harness/test_review_gate.py`, and
`tests/test_engineering_quality_skills.py`.

## Limitations

The default smoke proves command and payload composition. The opt-in live CMUX
probe additionally proves bounded create/observe/split/close behavior, but not
provider intelligence, authentication availability, terminal rendering,
callback deadlines, or the complete Harness lifecycle. Real provider dogfood
and the exact-HEAD release gate remain separate evidence. A new transport shape
must first be added here as a disposable RED-capable probe; it does not justify
a new runtime abstraction by itself.
