## Protected behavior verdict

- `implementation-plan` remains read-only, owned, evidence-mapped TDD planning.
  Stateful finalization now requires atomic cycles 1–5 and zero-effect sixth
  reservation proof; standalone Deep is explicitly outside that route matrix.
- `dispatch` still gives effects to code-owned runners. Continuable work stays
  in cmux. Only registered bounded review/schema adapters may select ephemeral
  execution after preflight, fixed argv compilation, schema validation, bounded
  capabilities, and durable receipts; direct print-mode stays forbidden.
- `review` preserves standalone default Deep as independent Anthropic+OpenAI
  holistic lanes. Finalization alone uses primary cycles 1–3 and typed adaptive
  cycles 4–5, with explicit single-model precedence and one terminal exact-HEAD
  attempt per reserved cycle.

## Join wiring

- Provider/runtime integration consumes the compiled logical routes from
  `compile_task_finalization_routes` and does not add transport names to the
  public DSL.
- The finalization controller calls `reserve_task_finalization_cycle` before
  any provider effect and completes that exact reservation terminally.
- Provider availability reaches the compiler only as typed
  `AvailabilityEvidence`; absence, staleness, or denial preserves the primary
  fallback.
- Existing persisted PipelineSpec v1 bytes omit `finalization_policy` and keep
  their historical compiled hash. New dispatch metadata freezes the additive
  five-cycle policy for integration.
