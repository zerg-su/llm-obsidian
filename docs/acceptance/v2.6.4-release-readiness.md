## Exact release invariants

- Harness is the only lifecycle owner. Model output affects state only through
  a validated typed artifact.
- Callback submit recovery consumes the existing generic `nudge_count`; it has
  no second model-call or submit budget.
- Provider, review, verification, nudge, restart, deadline and permission
  ceilings are not broadened from 2.6.3.
- A cmux transport success is not provider acknowledgement. Continuation
  success requires typed output or an observed exact-session state change.
- No prompt body, screen body, finding body, command body or error text is added
  to content-free telemetry.
- Plan review is purpose-safe and full canonical Git OIDs remain mandatory.
- Wiki repair uses the existing parser and sole transactional writer; ambiguity
  has zero mutation.
- PipelineSpec schema and public review topology are unchanged.

## Review and external-effect boundary

Anthropic/Fable/Opus review for this run. The review must cover intent and
engineering on exact HEAD, use the normal harness-owned callback path, and leave
no unowned reviewer resources. Full review is not selected automatically.

require a separate user-authorized effect. The RC may be handed off only with
the exact HEAD, green command evidence, terminal review result, and any honest
