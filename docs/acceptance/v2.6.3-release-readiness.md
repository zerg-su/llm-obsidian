## Allowed regression repairs

Commit `505bcc1` makes exact accepted-callback completion generic for any
operation whose durable callback identity is accepted before cleanup; it is not
restricted to research. The research workflow is the regression case exercised
by this release. Review-resolution decision
`4742e084-a96d-4371-afb5-bda2496a6434` narrows the recovery contract: a terminal
parent is rejected before artifact preparation,
synthesis child creation, surface allocation, or provider start; it is never
reset or replaced. An exact-identity cancelled fetch receipt may recover only
while that parent is nonterminal; digest, run, request, and artifact identity
must all match, and a mismatch creates no synthesis child or provider start.
Cancelled-synthesis recovery remains removed. Focused tests preserve normal
fetch cleanup, bounded cancelled-fetch recovery, and parent-stage agreement.

Commit `e85ad74` is the separately classified MCP bootstrap repair. It grants
only the wrapper-owned default `sync-config --apply` path authority to create
missing canonical `runtime.env` from the validated sibling example through the
existing atomic writer at mode 0600. A 25-case bootstrap matrix proves
check/print, environment/custom/direct paths, missing/invalid/symlink inputs,
and symlink targets write nothing, while creation and replay are deterministic.
Coordinator decision `70acb04f-5542-4e90-9466-94193b369181` explicitly
authorizes this second runtime exception. It is a disclosed deviation from the
original single-exception E7 wording, bounded to that default-path write
authority with no provider, permission, network, or pipeline-policy change.
The coordinator-owned durable record is
