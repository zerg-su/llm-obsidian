# 2.9.1 startup acceptance boundaries

The candidate retains the Plan U implementation and historical evidence described
in [2.9.0 acceptance](v2.9.0-plan-u.md). Those approvals and native schema samples
are not approval or GREEN of this new commit.

The new narrow stage establishes two behavior-bound checks: literal complete
Codex composer identity through an owned native editor handoff, and immutable
startup ownership through a held initial-input failure. The coordinator keeps
RED/GREEN logs, source hashes, prototype identities, advisory snapshot and final
live receipts outside the product worktree.

The no-model terminal control probe distinguishes ordinary byte 0x07 delivery
from missing delivery with the same enhanced keyboard flags enabled by Codex.
A separate installed-Codex probe checks both independently selected buffers with
the child-local fallback. Neither probe sends Enter or submits a model request. A cold-to-configured
control also demonstrates that the provisional startup composer ignores the
editor handoff. Regression checks require the configured context footer before
the initial handoff, without widening the existing readiness deadline.

A final-HEAD native attempt accepted initial input and the first callback but
failed continuation with `composer-unavailable`; exact resources were released.
That failure remains preserved. The user then authorized a shorter outcome:
reproduce continuation in a separate window, transfer the confirmed correction,
run focused regressions and commit once more without another broad acceptance.

The separate-window control demonstrates immediate failure while Codex is active,
then successful same-session second input/callback after native idle. Production
waits through activity within its existing observation count/interval, checking
ownership and artifact arrival before input. Exhaustion sends nothing. The
focused matrix covers these boundaries; native prototype evidence does not
claim a complete lifecycle on the final source commit.

The limited final disposition binds the exact candidate and discloses the waived
full lifecycle, Claude cells, full suite/mutation/schema reruns and approval-capable
review. No agent push, tag, PR, release or plugin update is performed.
