# v2.6.6 RC3 release readiness

RC3 starts from exact released RC2 commit
`b86a33d779bd8852915a4b875f12ef9a9b7366b3`. The immutable release-final
receipt, not a self-referential tracked claim, binds the exact candidate HEAD,
profile, commands, exit codes, output byte counts, and output digests.

[`RC3 evidence contract`](v2.6.6-rc3-evidence-contract.md). Focused slice

## Candidate policy

Every `release-final` profile execution is reserved in the external append-only ledger before its first command and recorded before interpretation as
`published`, `unpublished`, or `test-only`. All three classes consume the
five-attempt ceiling. A sixth execution has no authority. Any product edit
after an accepted verdict invalidates the disposition and requires a new
counted candidate attempt.

The canonical evidence root is external to the candidate checkout. It contains
the ledger, gate bundle, exact-head inventory, two review callback/meta pairs,
finding proof, and final disposition. Publication attaches that directory as
release evidence; no tracked file claims to identify its own containing commit.

## User-owned release commands

The following block is fish-compatible and intentionally not executed by the
Harness. Run it only after confirming the final exact candidate SHA reported by
the Harness and reviewing the release diff:

```fish
set rc3_branch task/llm-obsidian-2-6-6-rc3-release
set rc3_tag v2.6.6-rc3
git switch main
git merge --ff-only $rc3_branch
git push origin main
git tag -a $rc3_tag -m "LLM Obsidian 2.6.6 RC3"
git push origin $rc3_tag
gh release create $rc3_tag --prerelease --title "LLM Obsidian 2.6.6 RC3" --notes-file docs/releases/v2.6.6-rc3.md
```

These commands merge, push, tag, and publish. They remain outside this task's
authorized effects. Plugin installation or update is likewise intentionally
deferred to the user after publication.
