# LLM Obsidian 2.6.4 Harness control-plane baseline

The machine-readable authority matrix is
`docs/acceptance/v2.6.4-harness-control-plane-baseline.json`. Every row names
one lifecycle stage, its current owner, exact production module, observable test
seam, manual-ingress status, and baseline disposition.

The baseline finds two bounded product gaps. Reviewer callback submit can stop
at model prose without a typed artifact, and durable supersession does not yet
drive exact-owned old resources to resource-free terminal state. Existing typed
input/callback ingestion also lacks a code-owned fast path. These are owned by
Slices 1–5.

Plan-step selection, loops, review launch, verification, bounded fix/retry, and
checkpointing are already Harness-owned; Slice 5b adds independent prose-only
and duplicate-effect regression controls for those rows and changes no
production owner unless a new RED proves a gap. Workstream integration join is
coordinator-owned and deliberately absent from the stage list.

The invariant is binary: lifecycle state changes only from code-owned policy
plus a validated typed artifact. Terminal prose alone has zero transition and
normal unattended progress needs no manual `current` or `resume` command.
