## Model-free release gates

This tracked ledger intentionally does not claim that its own containing commit
is the final release SHA. The authoritative final verification packet includes
the content-free machine receipt at
`.vault-meta/release-evidence/v2.6.2-final.json`; that receipt records the exact
Git HEAD, each command, and each exit code. The recorded sequence is:

```bash

python3 scripts/validate-vault.py --summary
python3 scripts/codex-adapter.py --check

```

The final receipt is generated only after the resolution commit is frozen, so
it cannot become stale through an evidence-only follow-up commit. A read-only
reviewer can inspect the receipt and independently reproduce the full suite by
checking its bound HEAD out into owned writable scratch and running the same
commands there.
