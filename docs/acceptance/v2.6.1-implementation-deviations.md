# v2.6.1 implementation deviations

The approved plan expected a narrow topology change. Full live dogfood exposed
pre-existing assumptions in the same review lifecycle, so the implementation
also repaired its exact continuation and cleanup seams.

## Added beyond the initial seam

- `runtime_session_checkpoint.py` owns durable checkpoint and exact cleanup
  identity instead of spreading provider evidence through review policy.
- `review_gate_continuation.py` owns replay-safe per-lane continuation effects.
- `task_review_delta_packet.py` owns bounded exact-HEAD delta transport.
- `task_review_resolution_flow.py` owns executor-to-reviewer resolution handoff.
- Public lane identities use stable provider names instead of mutable model
  aliases; this intentionally replaces the unreleased `fable-*` / `sol-*`
  draft vocabulary.
- Multi-lane findings receive a code-owned, axis-qualified aggregate identity
  after their exact lane callback is accepted. The original callback remains
  unchanged evidence, while independent lanes may safely choose the same local
  finding ID.
- Reviewer isolation was hardened as part of the topology change: Codex excludes
  ambient `/tmp` and `$TMPDIR` write roots, uses only lane-owned temporary
  scratch, disables reviewer network access, and filters credential-like shell
  variables. Claude uses the corresponding native product deny-write and
  lane-only allow-write profile.
- Intent and holistic prompts always apply the Outcome Contract checklist. An
  absent implementer summary no longer suppresses outcome review.

These modules use the existing `OperationStore`, `RuntimeSessionManager`,
review gate, callback broker, and cmux ownership. They introduce no second
scheduler, store, state machine, lifecycle owner, implicit Full selector, or
pipeline parallel/join primitive.

## Why the deviation was accepted

The Full smoke made existing lifecycle defects reproducible: missing checkpoint
receipts, partial four-lane continuation, oversized exact deltas, and cleanup
identity after provider exit. The same smoke also exposed ambient-temp Codex
writes, lane-local finding-ID collisions, and a summary-dependent outcome
checklist. Keeping the repairs local to existing owners produced deterministic
regressions and preserved the approved Outcome Contract.
The release stops if its final explicit Full smoke or exact-HEAD review is not
green.
