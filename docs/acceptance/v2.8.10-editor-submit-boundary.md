# v2.8.10 editor/submit boundary acceptance

## Scope

This patch repairs the cmux transition regression exposed by the fourth
mirrored 2.8.9 dogfood. It changes no provider route, model call, pipeline
primitive, permission, dependency, workspace topology, or publication effect.
It supersedes only the editor-write portion of the 2.8.8 ordered-transition
contract.

## Corrected transport contract

- A Harness message is written to one exact surface with `cmux send
  --surface`. This operation populates the current composer and does not own
  submission.
- Harness observes the exact prompt anchor in the current editor before it
  reserves and emits one `Enter`. The write and submit remain separate durable
  stages.
- `terminal.paste` is not an editor-write primitive. Live inspection returns
  `submitted:true` and the child consumes the canonical input without a later
  Enter, so using it here would cross the submit boundary twice.
- A Codex status repaint cannot outrun an accepted editor write: unchanged
  editor state remains inside the bounded visibility window even when the rest
  of the screen changes. Claude's alternate-composer protections remain
  fail-closed.
- Native provider dialogs are still classified before any editor write. Exact
  surface identity is validated by the adapter before both `send` and `Enter`.
- The obsolete `terminal.input.ordered.v1` capability branch is removed; no
  production Harness caller or misleading fallback remains.

## Deterministic evidence

- `tests/harness/test_continuation_delivery.py` covers unchanged idle and
  non-editor repaint windows and requires one editor write plus one Enter.
- `tests/harness/test_runtime_sessions.py` covers the initial-input owner;
  `tests/harness/test_task_escalation_records.py` covers coordinator relay.
- `tests/harness/test_transition_transport_stress.py` executes all nine
  registered transition corridors 50 times without a duplicate callback,
  prompt, Enter, or provider replay.
- `tests/harness/test_adapters.py` binds the composer write to exactly
  `cmux send --surface <uuid> <text>` with no capability probe or implicit
  submit.
- The complete Harness and repository gates pass.
