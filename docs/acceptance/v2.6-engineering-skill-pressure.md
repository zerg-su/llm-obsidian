# LLM Obsidian 2.6 engineering-skill pressure evidence

## Scope

This bounded live check addresses the five behavioral pressure scenarios from
`docs/skill-semantic-gap-audit-v2.6.0.md`. It is behavioral evidence for those
five risks, not a claim that fixture text or five calls prove universal model
quality.

The code-owned runner used Codex `gpt-5.6-terra` at `medium` effort in an
ephemeral read-only session. It supplied exact local skill/reference bytes and
the scenario, but withheld grading assertions and expected values. String
fields used an unordered vocabulary containing both acceptable and
unacceptable choices. The runner permitted no workflow launch or product
write.
