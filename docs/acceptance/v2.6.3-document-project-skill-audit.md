## Evaluation protocol

named the defects and the no-skill control correctly rejected every one. The
replacement evaluation asked two fresh-context executors to create the same
four ordinary artifacts. Expected answers, grading fields, repository context,
and the authoring discussion were not supplied.

| Arm | Fresh task | Model / effort | Context |
|---|---|---|---|

The assignments covered a whole-project handbook, beginner concept ordering,
a runnable mutating command, and an evidence-based release ruling. The

[`v2.6.3-document-project-skill-pressure.md`](v2.6.3-document-project-skill-pressure.md).
