# LLM Obsidian v2.9.6

Released on 2026-10-24.

`reap` now removes eligible completed task worktrees after saving the result,
archiving the task, and shutting down its provider. This closes the lifecycle
gap that left a checkout behind for every successful task or retry.

- Git branches and commits are preserved; deletion never uses `--force`.
- Tracked changes, unknown files (including ignored files), active bindings,
  locks, unresolved plan-close conflicts, missing ownership, and the caller's
  working directory retain the checkout with an explicit reason.
- Known task metadata and Python bytecode caches do not prevent removal.
- A small durable receipt in the coordinator vault supports retry after
  removal and crash recovery without another vault write or provider shutdown.
- Shared-plan tasks can release their worktree while keeping the master plan.

There is no automatic sweep of old worktrees. Legacy/unowned checkouts and
unknown pipeline outputs require inspection. Branch pruning remains separate.
