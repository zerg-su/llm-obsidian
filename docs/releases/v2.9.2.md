# LLM Obsidian v2.9.2

Prepared on 2026-10-03. Publication is performed by the user.

This patch follows published v2.9.1 and fixes owned Codex input and cleanup:

- Retained worker notifications use their configured ComposerPort. Complete
  logical-buffer identity authorizes Enter; accepted replay adds no input.
- Recheck bound artifacts and ownership after blocking editor handoff and
  durable paste, initial-submit and retry-submit reservations. Lost ownership
  or a newly accepted artifact stops further input; prior submit counts remain.
- Close only the exact owned workspace with its sole owned surface after both
  processes exit. Foreign tabs and ambiguous geometry reject cleanup; waiting
  for disappearance does not repeat the close effect.
- Reviewer completion waits for the exact accepted callback's provider result
  before exit. Invalid event order is rejected before write-ahead publication.
- Register the existing review continuation module in the coverage manifest.

Claude and Codex plugin metadata both declare 2.9.2. Runtime behavior is unchanged
from reviewed implementation 4c48bea07f612d8aac616a053af692c82ee03bdb;
this packaging commit changes only version metadata and release documentation.
