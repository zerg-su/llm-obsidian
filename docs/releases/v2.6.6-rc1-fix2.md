# LLM Obsidian v2.6.6 RC1-fix2

RC1-fix2 is a narrow cleanup-reconciliation patch over
`v2.6.6-rc1-fix1`. It fixes one live protected-research failure without
changing the RC1 lifecycle architecture or replaying an accepted effect.

## Exact closed-surface reconciliation

After a successful provider exit, recent cmux versions can return an empty
identity object because the target surface is already gone. The adapter used to
reject that response before consulting the exact cmux tree. Harness therefore
retained stale process, supervisor and surface ownership even though
`request-exit` and `exit.json` proved a clean exit.

The adapter now treats a missing caller identity as an input to its existing
exact-tree fallback. It reports `missing` only when the requested surface is
also absent from that tree; a present or mismatched surface remains fail-closed.

## Live evidence

The originating dogfood operation preserved its accepted fetch callback and
cited artifacts, reconciled the completed exit without another fetch or model
call, cleared all exact owned resources, ran synthesis, and terminalized the
fetch, synthesis and parent research operations as `complete`.

The regression is deterministic and exercises the closed-surface response
directly. No schema, provider route, permission, pipeline, migration, or public
interface changes in this patch.

The previous RC1 tags remain immutable. This patch is published separately as
`v2.6.6-rc1-fix2`.
