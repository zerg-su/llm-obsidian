# LLM Obsidian v2.9.7

Prepared on 2026-11-11.

This release adds exact-session opening in Orca and completes native chat close.

- **orca-open-session** searches wiki provenance and each discovered connection's
  enabled Orca index, then opens the selected full Claude/Codex provider ID in
  its exact environment and workspace. There is no fixed connection-name list.
- **find-session** stays read-only and links explicitly requested Orca opening
  to the new skill. Existing optimized retrieval examples are preserved.
- **close** flushes recovery, reindex, validation and the scoped vault commit
  before closing the exact native chat through the checked host API. It proves
  the tab disappeared and its neighbors remain. Failed validation keeps it open.
- Runtime, workspace and provider identity checks, private write-ahead receipts,
  and bounded read-only reconciliation prevent blind duplicate launches.

Live acceptance used isolated test conversations. Claude topic lookup and repeat
focus passed; Codex fresh resume, repeat focus and native close passed. The
Claude seed's OAuth token was revoked (401); no credentials or settings changed.
Remote discovery/index status was checked, but no remote conversation was opened.

The internal fallback opens terminals and requires compatible installed runtime
modules and matching host/CLI versions. Unknown or unsupported hosts fail
explicitly. A documented public resume command takes precedence when available.
