# LLM Obsidian v2.9.7

Candidate prepared on 2026-11-11.

`close` supports Orca native chats: save through the existing writer, flush and
validate turn-end, then close the current chat tab through native Computer Use.
The tab receives a unique `Saved · close-<session_id>` title to bind the GUI
operation to the caller; this title remains in session history.

The runner recognizes a structured Orca session before inherited cmux metadata.
It returns preparation status with the exact chat ID, never a false closed
receipt. Blocked or incomplete turn-end cannot authorize closing. Missing GUI
access leaves a saved chat open for manual closure. Terminal sessions retain
the existing Claude/Codex cmux graceful-exit behavior.

Orca currently has no native `chat close` CLI command. GUI closure is conditional
on a visible window, Computer Use access and an unambiguous marked tab/button.
The current headless runtime reports `window_not_found`, including one restore
attempt. Live rename/click/disappearance acceptance is still outstanding; the
hermetic runner tests establish routing and save gating only.
