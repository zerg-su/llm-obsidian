# LLM Obsidian v2.6.6 RC4-fix1

RC4-fix1 is a bounded dogfood patch over `v2.6.6-rc4`. It packages seven
bounded dogfood fixes discovered while exercising the released Harness in LLM
Obsidian Swarm. It does not change the RC4 pipeline DSL, review topology,
provider routing, permission model, or release evidence contract.

## Dispatch and review continuation

- Reviews can start from the exact owned offscreen cmux surface. Visibility of
  the coordinator surface is no longer a hidden launch precondition.
- Dispatch diagnostics bind to the durable Harness owner.
- A recoverable review-drive failure resumes the exact live executor instead
  of opening an unowned continuation.
- Claude callback permissions use edit-only path rules accepted by the current
  runtime rather than an unsupported write rule.
- A terminal review-resolution handoff consumes its exact durable accepted
  findings and resumes once without replaying reviewer, callback, or provider
  effects.

## Cancellation and vault safety

- `harness-cli cancel|close` traverses the exact owned lifecycle subtree
  child-first. A nonterminal descendant produces a truthful partial result and
  nonzero exit instead of leaving children behind while claiming success.
- Folded log extracts preserve safe Obsidian wikilinks.

## Verification boundary

The patch carries focused regressions for offscreen launch, owner-bound
diagnostics, live executor continuation, Claude permissions, exact subtree
cancellation, wikilink-safe folding, and terminal resolution handoff. The
terminal handoff change also passed the configured Opus high implementation
review at exact HEAD `633e7f7cfe4a26f42fb5aba5b9dda5092de53adf`.

This checkout prepares a local release commit only. It does not push, tag,
publish, install, or merge. The immutable `v2.6.6-rc4` tag remains unchanged;
this patch is published separately as `v2.6.6-rc4-fix1`.
