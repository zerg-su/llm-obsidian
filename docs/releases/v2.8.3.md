# LLM Obsidian v2.8.3

Version 2.8.3 repairs the transition failures exposed by the mirrored 2.8.2
dogfood runs. It is a patch release; pipeline contracts and model-facing skill
interfaces are unchanged.

## Transition recovery

- Durable custom-step callbacks take precedence over retained notification
  recovery, so an already completed model step advances without another
  transport attempt or provider replay.
- Same-HEAD Outcome Contract amendments archive the terminal review callback
  before launching a successor with a fresh outbox.
- Repository-owned transition failures raise a typed mechanism escalation and
  wake coordinator self-heal. Model artifact failures remain ordinary
  attention boundaries.
- The explicitly authorized `cancel-stale` command retires only expired,
  narrowly classified pending effects after exact resource checks. It is
  signal-free, replay-free, atomic across the exact subtree, and refuses live,
  unknown, or identity-drifted ownership.
- Upgrade preflight recognizes a durable archived review even when its retained
  transport marker is still close-armed.

## Evidence

- Disposable transition prototypes cover 15 transition cases and 10 stale
  effect/self-heal cases before production promotion.
- Regression tests cover callback/result races, self-heal escalation,
  authorized stale retirement, concurrent revision drift, subtree ordering,
  and archived-review preflight.
- The complete repository test gate passes on the exact release candidate.
- The active authority contour is exactly 28 files / 16,387 LOC and the live
  scripts ratchet is exactly 296 files / 113,203 lines, both with zero
  speculative headroom.
