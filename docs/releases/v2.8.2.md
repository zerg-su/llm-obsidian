# LLM Obsidian v2.8.2

Version 2.8.2 closes the cmux liveness and retained-session submission races
observed during the mirrored 2.8.1 dogfood runs. It is a patch release; skill,
pipeline, and public artifact contracts are unchanged.

## Semantic liveness

- `CmuxAdapter.agent_status` binds one exact workspace and runtime to cmux's
  content-free provider status: `claude_code` for Claude and `codex` for Codex.
- The decoder is strict, rejects duplicate or malformed provider rows, and
  normalizes only `Running`, `Working`, `Idle`, and `Needs input`.
- Liveness retains screen digests for evidence but no longer treats changing
  screen bytes as progress while semantic status is `Idle` or `Needs input`.
  This prevents token counters and other status-line repaint from hiding a
  stalled retained session indefinitely.

## Retained notification delivery

- Custom model-step, custom finalization, engineering/fix phase, and
  engineering/fix finalization notifications prove that the exact prompt is
  visible in the provider editor before sending `Enter`.
- Historical `sent` notifications that are still visibly present in an idle
  editor can be submitted once through an identity-bound durable recovery
  receipt. The recovery never re-pastes task text and a reserved-but-unsettled
  submit remains fail-closed.
- Fresh delivery records paste and submit reservations before their respective
  cmux effects. A pre-send editor digest prevents an unrelated collapsed Codex
  placeholder from proving the current paste.
- One thread/process lock linearizes receipt inspection through `Enter`, so
  simultaneous worker wakeups converge on one provider-facing key.
- Recovery checks only the active provider composer, so a matching completed
  transcript cannot submit an empty or unrelated current draft.
- Review callback recovery consumes the checkpoint state re-established by its
  durable rehydration pass, avoiding a stale checkpointless classification.
- If HEAD changes after the callback becomes durable, the frozen callback is
  terminalized before reserving the changed-HEAD successor, so its immutable
  attempt identity is never rebound.
- Accepted predecessor callbacks are archived before their axis outbox is
  reused. Direct same-cycle predecessor recovery closes a durable zero-effect
  launch-failure prefix without repeating a reviewer effect.

## Evidence

- A disposable live prototype on cmux 0.64.22 observed exact Claude states
  `Needs input` and `Idle` without reading screen content.
- Adapter, liveness, continuation-delivery, custom-runtime, engineering/fix,
  review-resolution, and crash/restart regression corridors cover the repair.
- The active authority contour is exactly 28 files / 16,259 LOC with zero
  writable authorities, zero incident literals, and zero headroom. The live
  scripts ratchet is exactly 296 files / 112,961 lines with zero headroom.
