# LLM Obsidian v2.9.0

Prepared on 2026-09-29; release candidate completed locally on 2026-10-02.
Not yet tagged or published.

Version 2.9.0 adds semantic mutation testing to the TDD workflow, integrates
the skill contract audit and repairs review recovery and Codex/cmux integration.

## Skills

- New `mutation-testing` checks whether green tests reject plausible behavioral
  defects. The runner captures current source bytes, uses a fresh isolated copy
  for each mutation, requires green baseline/control runs and verifies that the
  original source stayed unchanged. Copy isolation is not a network sandbox.
- `tdd` requires this stage after every GREEN run. Results distinguish killed,
  survived, equivalent, invalid and inconclusive mutations. A passing sample
  does not establish project coverage or replace parent acceptance gates.
- `daily` delegates to the in-process Claude summarizer using session credentials
  without a redundant standalone authentication probe.
- `defuddle` cleans local HTML; URLs go through protected `wiki-ingest`.
  `draft` consumes pasted or local thread text and resolves routine choices
  through defaults before asking for clarification.
- `wiki-ingest` reads pages being updated fully, checks contradictions before
  writes and uses one final transaction for a batch. `wiki-lint` separates its
  report transaction from approved fixes. Save/query/lint templates carry the
  required provenance and lifecycle fields and are checked by the validator.
- `find-session` uses runnable JSONL lookups, `backlog` matches exact slugs and
  canvas read operations report missing files without creating them. Dated
  guidance in planning, dispatch, review and learning becomes stable contracts.

The prompt audit originally targeted an unpublished 2.8.11. Its
[detailed notes](v2.8.11.md) are retained as part of this combined release.

## Runtime and recovery

- The registered Codex schema profile explicitly disables web search and binds
  quoted input to the workflow's declared operation scope at developer level.
  This does not change ordinary app/TUI host policy. Compiler and native
  configuration checks establish the binding; behavioral acceptance is separate.

- Codex defaults to `gpt-6-astra`; role-specific review routes remain independent.
- Native folder-trust and activity screens from the updated Codex interface are
  recognized, and cmux surface closure binds the containing window. Terminal
  read/send/send-key also bind both the observed workspace and window, so
  offscreen I/O does not depend on the selected workspace.
- Blocked current reviews can retry committed corrections while retaining
  dirty-tree and active-lease guards. Callback replay preserves terminal state
  and avoids duplicate provider effects when no executor summary exists.
- `scripts/codex-auth-backup.py` supports local backup, account switching and
  restore for file-based login. Restoring a cache cannot revive revoked tokens.
- The lifecycle simulator resolves Apple's Git launcher once, preserving the
  caller's Python/custom Git selection and the existing 60-second timeout.

Registered live lifecycle probes use an isolated workspace so a crowded origin pane cannot collapse their terminal width. They now acquire exclusive supported interactive task context before provider start. Hooks retain task telemetry without indexing or committing the release vault. Same-parent continuation advances only its acknowledged input delivery generation, retaining the original callback/result generation; replay retains the acknowledged receipt and sends no second prompt. Input-only receipts live in a separate namespace and do not acquire provider result/exit obligations. An already broker-accepted parent callback is sealed before continuation transport, retaining its original result authority. Production worker exit and ordinary exact cleanup are covered; a genuinely missing required result remains blocked. Existing foreign or changed task context is preserved.

Continuation delivery waits for delayed repaint of the unchanged idle editor within the existing observation budget. New prompt visibility precedes Enter and provider activity acknowledges submission. Changed drafts, interactive blockers and ownership loss never authorize submission.

Before Enter, the complete current composer must match the intended prompt, including the contract path/hash. Native wrapping is allowed; shared prefixes, historical anchors and generic pasted-content placeholders cannot authorize submission.
