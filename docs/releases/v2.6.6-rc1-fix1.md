# LLM Obsidian v2.6.6 RC1-fix1

RC1-fix1 is an interim dogfood patch over `v2.6.6-rc1`. It keeps the RC1
deletion-first architecture unchanged and repairs four concrete failures in
visible cmux/Codex dispatch and exact-HEAD review finalization.

## Dispatch startup

- Codex resume commands now carry the exact task worktree explicitly. The
  native current-folder/worktree chooser can no longer redirect an unattended
  task into another checkout.
- Provider startup failures retain bounded diagnostics and typed transport
  stages instead of collapsing into an empty terminal with no actionable
  evidence.
- A newly created cmux terminal is treated as asynchronously ready. Harness
  retries transient empty or malformed reads for a bounded interval before it
  sends the command or returns typed attention.

## Review skip

An exact-HEAD task compiled with `review.mode=skip` now takes the same
code-owned terminal path as other review outcomes while creating zero reviewer
and provider effects. This closes the failure observed after a valid
zero-change task summary.

## Verification boundary

The patch is covered by focused regressions for runtime launch, continuation,
terminal readiness, exact-HEAD review attempts, and task lifecycle. It adds no
new pipeline, schema, provider route, permission, migration, or external
effect. Broader lifecycle cleanup and upgrade/configuration work remain in the
2.6.6 RC2 ledger.

The original `v2.6.6-rc1` tag and its evidence remain immutable. This release
is published under the separate `v2.6.6-rc1-fix1` tag.
