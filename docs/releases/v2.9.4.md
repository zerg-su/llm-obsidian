# LLM Obsidian v2.9.4

Prepared on 2026-10-16. Publication is performed by the user.

This patch release follows published v2.9.3:

- `docs/skill-references/plain-style.md`: Russian passages also follow
  GOST R 2.105-2019, clauses 5.2.2–5.2.3, on top of STE. The rule asks for
  concise, unambiguous wording and consistent terms, and keeps requirements
  apart from permissions and possibilities. Project terminology still takes
  precedence. English text is unchanged.
- `skills/tech-doc/scripts/doc_lint.py`: longer code fences and their
  language tags parse correctly. An empty gloss no longer counts as a gloss.
  A table cell is reference-only only when its other words are connectors.

Skill descriptions, `CLAUDE.md` and `AGENTS.md` are unchanged.

[CHANGELOG.md](../../CHANGELOG.md).
