# LLM Obsidian v2.6.6 RC4-fix3

RC4-fix3 is a bounded dispatch-profile reconciliation patch over
`v2.6.6-rc4-fix2`. It contains one universal correction found while integrating
Fix2 into a separate Swarm vault. It adds no dashboard or lifecycle behavior.

## Target-local Codex dispatch profile

- When the target repository carries `.codex/dispatch-env.toml`, dispatch now
  runs both MCP configuration sync and the selected Codex profile sync through
  that target repository's gateway and working directory.
- A target without its own dispatch profile retains the existing vault-local
  fallback.
- The focused regression verifies the observable gateway path and working
  directory for both sync commands before any task worktree is created.

## Fork-stable engineering evidence

- The frozen RC4 engineering eval normalizes only three registered
  `llm-obsidian-swarm` branding aliases before source hashing and prompt
  compilation.
- Canonical and Swarm repositories therefore compile byte-identical evaluation
  prompts without weakening the governing contract; any unrelated source
  mutation still fails closed before provider execution.

## Scope

This patch does not change pipeline DSL authority, review topology, callback
ingestion, verification policy, provider routing, Harness state transitions,
or the external read-only dashboard. The pending browser-dashboard proposal is
not part of this release.

## Verification boundary

The focused dispatch regression, Harness suite registration, documentation and
version contracts, scope ratchet, plugin packaging checks, and the configured
hermetic suite must be green on the exact release candidate.

This checkout prepares a local release commit only. It does not push, tag,
publish, install, or merge. Existing release tags remain immutable; this patch
is published separately as `v2.6.6-rc4-fix3`.
