# LLM Obsidian v2.6.7 RC1

RC1 is a bounded Harness stabilization release over `v2.6.6-rc4-fix3`.
It hardens one supported `engineering/change` corridor and the durable
authority used to prove its progress. It does not claim general Harness
reliability across every legacy pipeline or recovery path.

## Durable lifecycle recovery

- Worker restart can resume the named verification, review-drive, callback
  wake, findings, refreshed-summary, and reap boundaries without treating
  screen state or elapsed time as positive authority.
- Product fix cycles are counted separately from mechanism recovery. The third
  material failure freezes a structural pivot boundary and requires the
  configured independent high-reasoning route before further product work.
- Failed or invalidated live cells reset their streak only from exact durable
  operation, identity, terminal-state, and resource-cleanup evidence.
- Approved cleanup can terminalize after exact owned resources have already
  been released, without replaying a reviewer or provider effect.

## Deterministic evidence

- A production-core hermetic world executes the complete supported corridor
  and a crash/restart matrix at every named durable handoff.
- The RC1 gate reserves each configured cell before launch, rejects caller
  completion claims, and re-derives positive and negative outcomes from the
  real OperationStore, callbacks, verification effects, Git identity,
  finalization ledger, and resource inventory.
- The three-cell hermetic regression proves streak values 1, 2, and 3 with a
  material review/fix cycle and `complete=true`.

## Deferred live acceptance

The provider-backed live streak remains intentionally deferred until RC3,
after RC2 has changed the behavioral subject with the root-scoped dashboard.
RC3 must run three fresh sequential cells on the final post-RC2 digest, then
the planned sequential and parallel dogfood. These deferred receipts are not
claimed by RC1.

## Verification boundary

The RC1 stabilization suite, lifecycle crash matrix, Harness state/recovery
regressions, plugin packaging contracts, instruction/skill budgets, code
quality audit, and configured hermetic release gate must pass on the exact
release commit.

This release is published as the prerelease tag `v2.6.7-rc1`. It is intended
to provide a fresher, deterministic base for Swarm integration and RC2 work.
