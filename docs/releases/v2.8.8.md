# LLM Obsidian v2.8.8

Version 2.8.8 is an ordered-transition stabilization release after 2.8.7. It
preserves the task-centric workspace topology and state-machine semantics while
repairing the cmux delivery boundary exposed by mirrored dogfood.

## Ordered agent input

- Harness editor input now uses cmux's capability-advertised
  `terminal.input.ordered.v1` transport with an explicit surface UUID and an
  exact response check.
- All executor, custom, fix, verification, summary, review, liveness, callback,
  and coordinator-escalation wakes share that transport.
- Paste visibility and `Enter` remain separately observed. A transient unchanged
  idle frame no longer converts a valid paste into immediate attention.
- Older cmux builds retain the exact-surface legacy fallback.

## Idempotent callback publication

- Repeating the exact canonical callback publication is now a successful no-op.
- Concurrent identical submitters converge on one immutable outbox; foreign or
  changed bytes remain fail-closed and are never replaced.

## Evidence

- The live Claude prototype reproduced the legacy lost-input race, then passed
  ten consecutive ordered-paste deliveries; the production adapter completed a
  real Sonnet Low turn with exactly one accepted submit.
- The transition stress gate covers nine registered production corridors for
  50 repetitions each.
- The callback regression races 50 identical publishers and proves immutable
  convergence plus foreign-byte rejection.
- Full Harness, model-routing, repository, and mirrored post-install dogfood
  gates are required before publication.
