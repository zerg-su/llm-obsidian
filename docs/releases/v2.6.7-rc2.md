# LLM Obsidian v2.6.7 RC2

RC2 adds a root-scoped Harness observer over the bounded lifecycle stabilized
in RC1. It replaces the normal global dashboard projection with one external
read-only observer per exact dispatch root while retaining explicit `--all`
diagnostics for operators.

## Root-scoped observer

- The dispatch `request_id` is the root operation identity before provider
  launch, so its observer can open first and display early startup failures.
- The normal dashboard requires one exact root and projects only that root and
  its descendants. Historical owners no longer crowd the active view.
- The cmux marker binds vault, workspace, and root operation identity. Repeated
  calls for one root reuse the same split; concurrent roots receive separate
  splits.
- Current steps expose runtime, model, effort, preset, visit/cycle state, and
  bounded issue details while completed and future steps stay compact.
- The observer remains external and user-closed. Harness does not treat its
  surface as an owned resource or positive lifecycle authority.

## Bounded recovery repairs

- Recognized post-submit runtime dialogs are confirmed without resending the
  original prompt.
- Fable dispatches use dedicated workspaces by default.
- Reviewer startup publishes process readiness before semantic input
  acknowledgement. Exact late-start recovery validates process, supervisor,
  surface, provider, and callback identity and never replays provider input.
- An accepted callback belonging to one prior terminal review attempt is
  archived before a fresh zero-effect review cycle. Foreign, nonterminal, or
  ambiguous callback evidence remains fail-closed.

## Verification boundary

The exact candidate passed the 78-suite Harness registry, model-routing,
code-quality, documentation, instruction, skill-budget, runtime-session,
scope-ratchet, and review-resolution regressions. The final Fable High review
approved the candidate.

RC2 does not claim RC3 live acceptance. Fresh sequential and parallel dogfood
remain the next independently dispatched release stage.

This release is published as the prerelease tag `v2.6.7-rc2`.
