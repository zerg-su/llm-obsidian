# LLM Obsidian v2.8.11

Version 2.8.11 makes skill instructions consistent with their input boundaries,
writer transactions, and validated page schemas.

## Inputs and clarification

- `defuddle` cleans saved local HTML and routes URLs through protected
  `wiki-ingest`; its manual fallback still performs actual content cleanup.
- `draft` requests pasted or local thread text and checks facts through
  research/docs tooling. Defaults resolve routine choices before clarification.
- `find-session` keeps its read-only top-five preview, uses executable JSONL
  lookups, and removes the unused auto-inject branch and pseudo-extractor.

## Filing and retrieval

- Ingest reads updated pages fully, checks contradictions before writing, and
  collects batch page/manifest operations into one final writer transaction.
- Lint writes the report and optional dashboard first, then approved fixes in
  a separate transaction. Severity follows the validator; frontier links keep
  their existing treatment.
- Query uses retrieval plus navigation where needed. Save, lint, and query
  templates include required provenance and lifecycle fields; save templates
  contain no YAML comments and keep their explanations in adjacent prose.
- Backlog matches exact slugs and rechecks uniqueness after conflicts. Canvas
  open/status reports a missing file; creation belongs to explicit writes.

## Regression coverage

`make test` now includes the prompt contract checks and template tests. JSONL
and slug examples execute against local fixtures, and page templates run
through the real validator with an explicit scratch-vault root under TMPDIR.
The change also replaces dated guidance while preserving existing review,
planning, dispatch, and learning contracts.

On macOS, the lifecycle simulator resolves Apple's Git launcher once per run
to avoid repeated launcher overhead. Its 60-second limit and real Git checks
remain unchanged; the caller's Python and custom Git selection are preserved.
