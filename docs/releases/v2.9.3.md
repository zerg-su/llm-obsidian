# LLM Obsidian v2.9.3

Prepared on 2026-10-15. Publication is performed by the user.

This minor feature release follows published v2.9.2 and adds two skills for
plain technical writing:

- `tech-doc` writes or audits runbooks, READMEs and how-tos. It uses a
  quick-reference-first operations manual, S1000D-style procedures (signal
  word before the step, expected result after each step) and commands taken
  from the repository. Facts without a source are marked `(unverified)`.
- `plain-talk` is a strict pass for replies and text: about 80% of ASD-STE100,
  main point first, one term per thing, no AI-slop patterns.
- `docs/skill-references/plain-style.md` is the single source for both skills.
  `skills/tech-doc/scripts/doc_lint.py` checks sentence length, semicolons,
  word lists, unglossed ID references and EN/RU pair parity
  (`make test-doc-lint`).
- The skill description budget is 7800 bytes (was 7500). Existing skill
  descriptions are unchanged.

`CLAUDE.md` and `AGENTS.md` change only in the skill list. A vault that wants
the style on every reply adds one line that points to `plain-style.md`.

## Acceptance and limits

The owner approved the skills without a RED/GREEN evaluation. This release
claims no behavioral improvement over the no-skill baseline. Fresh-context
smoke runs and a five-pass `improve-skills` audit are recorded in
[tech-doc-plain-talk-adoption.md](../acceptance/tech-doc-plain-talk-adoption.md).
