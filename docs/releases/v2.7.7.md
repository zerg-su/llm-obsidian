# LLM Obsidian v2.7.7

Version 2.7.7 is a stability release for long-running Harness pipelines. It
consolidates the narrow 2.7.1–2.7.7 repair series without introducing a new
scheduler, lifecycle kernel, or broad compatibility layer.

## Reliable exact-HEAD continuation

- Verification attempts, invalidations, changed-HEAD handoff, controller
  admission, and review launch now consume exact durable receipt and HEAD
  authority instead of stale boolean observations.
- Missing or orphaned verification lineage fails closed without minting a
  replacement that could replay work.
- Provider start rechecks the verified candidate at the final effect boundary,
  preventing a late commit from launching review against stale evidence.

## Generation-bound cleanup

- Runtime cleanup uses the actual positive provider generation from the exact
  ready handshake rather than assuming generation 1 or substituting callback
  generation authority.
- Process, supervisor, surface, callback, and provider-generation identities
  must agree before resources are released. Missing, malformed, symlinked,
  stale, or drifted authority remains fail-closed.
- The same rules cover initial and replacement provider sessions and preserve
  already accepted callback authority.

## Final dogfood matrix

The final candidate was exercised from exact public `main` using five isolated
lightweight corridors with separate plans, worktrees, branches, and files:

1. Built-in OpenAI-local: Terra Medium execution to Sol Medium review.
2. Built-in OpenAI-to-Claude: Terra Medium execution to Opus Medium review.
3. Built-in Claude-to-OpenAI: Sonnet Medium execution to Sol Medium review.
4. Custom four-step OpenAI-to-Claude: inspect, implement, verify, review.
5. Custom three-step Claude-to-OpenAI: inventory, author, review.

All five reached terminal reap with closed plans and no reap warnings. The
four-step custom run exposed one minor observability/control-plane issue: after
the step callback had already been accepted, the child was complete and the
next request was minted, an executor still emitted a stale escalation. The
pipeline's code-owned recovery had already succeeded; automatic suppression of
that redundant escalation is deferred to the next patch and is not treated as
a 2.7.7 release blocker.

## Release boundary

- The disposable smoke branches and their prototype artifacts are not part of
  this release.
- This release does not merge, publish, or tag the coordinator Swarm vault.
- No new dependency, scheduler, provider fallback, or automatic live Harness
  mutation path is introduced.
