# LLM Obsidian v2.9.8

Codex lifecycle hooks now keep runtime writes out of the installed plugin
cache. A local marketplace can install a copy of the vault alongside the hook
scripts. When a shell command ran from that copy, the command hook could append
to the package's journal. Codex detected the changed package and required hook
approval again, including for the Stop hook in Orca Chat.

The hooks now skip cached vault copies and use the active vault when they find
one. With no active vault, they skip the write. Task markers and task origins
inside the cache cannot direct telemetry or command capture there.

Codex may ask you to review and approve the package after installing this version.
