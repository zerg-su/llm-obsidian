# LLM Obsidian v2.8.9

> Superseded transport detail: the ordered-paste inheritance described below
> was replaced in v2.8.10 after live cmux evidence showed that
> `terminal.paste` itself submits canonical input. The current editor/submit
> contract is recorded in
> [v2.8.10 acceptance](../acceptance/v2.8.10-editor-submit-boundary.md).

Version 2.8.9 is a focused compatibility stabilization after 2.8.8. Mirrored
dogfood exposed a new Claude Code native onboarding dialog that could appear
between two retained-session pipeline steps and consume the next task paste.

## Native-dialog containment

- Harness recognizes the exact Claude auto-mode environment onboarding and
  the in-progress setup wizard.
- Both dialogs are dismissed with `Esc`. Harness does not select an
  environment, persist a user preference, grant task authority, or replay a
  provider turn.
- Continuation delivery checks for a native dialog before reserving or pasting
  task input. Known dialogs wait for their deterministic handler; changed or
  unknown dialogs remain fail-closed.
- Paste and submit evidence retain the ordered exact-surface transport from
  2.8.8.

## Evidence

- The onboarding and wizard dismissal matrix completes 50 stateful
  transitions without changing the running operation state.
- Known and unknown dialogs both block paste before transport reservation.
- The transition stress gate remains green for nine registered production
  corridors with 50 repetitions each.
- The complete Harness gate passes, including built-in/custom, review,
  verification, recovery, callback, workspace, and dashboard suites.
