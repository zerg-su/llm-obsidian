# LLM Obsidian v2.9.5

Prepared on 2026-10-20. Publication is performed by the user.

This feature release follows published v2.9.4 and adds one skill:

- `drilldown` builds one self-contained HTML page for one object (pod, host,
  service) over one time window: stat tiles, stacked/bar/line panels on a
  shared time axis, a crosshair tooltip synced across panels, threshold lines,
  and a bucketed table. Light and dark themes use a fixed, validated
  8-color order.
- `scripts/drilldown.py` (stdlib only) has three commands:
  - `validate` checks the declarative spec;
  - `fetch` reads series from a Prometheus-compatible `query_range` API, read
    only; a bearer token comes from an environment variable named in the
    spec, never from the spec itself;
  - `render` writes the page. Series from other systems (error trackers,
    deploys) join through `--extra` with unix or ISO-8601 timestamps.
- Downsampling keeps bar sums and line maxima. Orca inline-visual limits
  (file name, 512 KB) are enforced; with `ORCA_CHAT_SCRATCH_DIR` set the
  command prints the `::orca-visual` line.
- Spec and data stay in a cache directory outside the vault, so a page can be
  re-rendered or attached through `/save`.

The skill description is 29 bytes; triggers live in the router. The skill
description budget is now 7798 of 7800 bytes, so the next new skill needs
shorter descriptions elsewhere.

`CLAUDE.md` changes only in the skill list. Domain recipes (endpoints, metric
names) are meant to live outside the plugin.
