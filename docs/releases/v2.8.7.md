# LLM Obsidian v2.8.7

Version 2.8.7 is a transition-liveness stabilization release after 2.8.6. It
preserves the task-centric two-workspace topology while closing the delivery
and self-heal races exposed by mirrored dogfood.

## Retained transition delivery

- An exact registered callback supersedes an unsubmitted notification without
  sending `Enter` or replaying the provider/model step.
- The supersession is recorded as a durable, identity-bound delivery stage.
- A busy editor leaves delivery safely pending for the next observation;
  uncertain paste or submit effects still stop fail-closed.
- The same behavior is shared by custom and engineering/fix transitions,
  including finalization handoffs.

## Liveness convergence

- Stable typed results reconcile once per exact operation revision and result
  digest.
- An unchanged result no longer monopolizes the observer. Existing bounded
  suspected-idle, nudge, restart, and attention behavior resumes normally.
- Revision or result changes open one new stable reconciliation identity.

## Evidence

- The provider-free transition stress gate covers eight lifecycle corridors
  for 50 repetitions each across Claude and Codex editor shapes.
- Focused continuation, liveness, custom runtime, task-summary, Harness,
  routing, and complete repository gates protect the surrounding behavior.
- A bounded real-cmux transport prototype and four fresh mirrored 2.8.7
  dogfoods are post-review promotion gates.
- The active authority contour is exactly 28 files / 16,493 LOC. The complete
  scripts contour is exactly 297 files / 113,856 lines. Neither has headroom.
