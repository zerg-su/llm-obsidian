# LLM Obsidian v2.8.10

Version 2.8.10 is a focused transport and configuration-sync stabilization
after 2.8.9. It restores the editor/submit ownership boundary proven by live
cmux behavior and closes the remaining Codex repaint and profile-backup seams.

## Editor and submit ownership

- `cmux send --surface` writes task input into one exact current composer.
- Harness verifies that editor state, reserves submission, and emits exactly
  one `Enter`. No adapter command owns both input and submit.
- The obsolete ordered-paste capability and implicit-submit path are removed.
  Native provider dialogs are still classified before any editor write.

## Codex repaint containment

- Pre-submit status repaints remain inside the bounded editor-visibility
  window instead of invalidating an accepted write.
- A transient idle frame immediately after submit is observed until real
  provider activity appears. The wait cannot emit a second prompt or `Enter`.
- Coordinator escalation and decision relays share the same editor preflight:
  native dialogs block all input, and a delayed repaint must expose the exact
  message anchor before one `Enter` is allowed.
- Those relays now reuse the retained-notification write-ahead receipt, so
  accepted replay is effect-free and editor-write/submit crash windows cannot
  repeat the prompt or `Enter`.

## Config-sync transaction safety

- Backup names use a bounded readable prefix plus the full SHA-256 of the
  canonical target path, avoiding filesystem component limits without hash
  truncation.
- Every backup is preflighted before the first target replacement, so an
  invalid backup cannot leave a partially applied profile sync.
- A clean `--apply` is side-effect free and does not create an empty backup
  directory.

## Evidence

- The provider-free real-cmux gate completed 50 Codex and 50 Claude
  coordinator-relay deliveries with zero provider/model calls and zero owned
  workspace tails.
- Ten production transition corridors passed 50 repetitions each; the full
  repository test gate passed afterward.
- The Codex MCP gateway suite passes 126/126 checks.
- Sol XHigh review identified both the coordinator preflight omission and its
  initial non-durable effect boundary; both are closed by the final descendant
  and its exact-HEAD receipts.
- The scripts contour is pinned to 297 files / 114,199 lines with no
  speculative headroom.
