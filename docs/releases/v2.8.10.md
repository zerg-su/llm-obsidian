# LLM Obsidian v2.8.10

Version 2.8.10 adds a repository-neutral review boundary and closes the
stabilization findings discovered while dogfooding it against external Git
checkouts.

## Review modes

- Light Review is a read-only same-runtime subagent review over a frozen Git
  snapshot. It inherits the current model by default and supports same-runtime
  model and effort selection without becoming an approval gate.
- Lifecycle Review owns a clean exact-commit lease, an explicit base range,
  immutable Outcome evidence, external scratch, and typed callback state.
- Current Full review keeps one fixed topology: Anthropic/OpenAI intent and
  engineering lanes at XHigh. Explicit routing or effort overrides fail before
  ownership and provider effects; configurable topology remains a Deep review
  concern.

## Stabilization

- Review coordinator discovery is independent from the reviewed repository.
- Missing targets, broken and escaping symlinks, dirty trees, generic evidence,
  stale plans, concurrent admission, and failed active-pointer publication all
  fail closed at their owning boundaries.
- Exhausted review lineages require explicit replacement authorization, while
  safe callback recovery reuses frozen plan bytes and preserves prior evidence.
- Local immutable implementation receipts bind the exact HEAD, complete test
  suite, diff check, and final clean status without entering product commits.
