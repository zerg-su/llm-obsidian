# Prototype

Ask one falsifiable question/criterion in a harness-owned disposable
worktree/minimal ContextPacket.
Answer with one run command/bounded evidence; production code remains
unchanged. No production tests/polish/compatibility/extras.

Durably record `Question`, `Evidence`, `Decision`, `Limitations`, `Provenance`
and how the local answer informs the incoming Outcome Contract. A successful
spike proves neither desired outcome nor production completion.

Keep off main. Clean only its exact worktree after decision is durably captured and idle. Unknown ownership -> `attention-required`;
never guess/clean broadly. Production promotion requires separate authorization.
