# 2.5 real dogfood RT06 runtime-neutral telemetry

## RT06 — runtime-neutral / evidence-bounded skill telemetry

Final HEAD `54bfac8` (initial `b6c60a4` + review resolutions). All five review
findings applied, none rejected, no escalation required.

**Defect.** `scripts/pipeline-stats.py` counts skill invocations from Claude-only
sources (`~/.claude/history.jsonl`, Claude transcripts), then printed an
unconditional `## Dead-weight candidates (N of M installed, 0 invocations ...)`
over every installed skill. Codex is skill-capable but leaves no trace there, so
absent Claude evidence was presented as proven zero usage —
and `skills/wiki-lint/SKILL.md` acts on that list as removal candidates.
Driving the report live also exposed a second false verdict: an empty evidence
window claimed all 32 installed skills were dead weight.

**Design (reused seams, no new telemetry system).** Both cross-runtime seams
already carry a `runtime` field — `.vault-meta/pipeline-events.jsonl`
(`pipeline_events.py`) and `.vault-meta/router-hits.jsonl` (`skill-router.py`).
No new source, file, schema change, or emission point. `classify_zero_usage()`
selects one of three honest headings:

| Heading | Condition | Meaning |
|---|---|---|
| `Dead-weight candidates` | usage observed, nothing could have invoked a skill unobserved | complete verdict |
| `Claude-zero skills` | Codex or unattributed orchestration observed | zeros unproven; router-matched skills held back from removal |
| `Skill usage evidence unavailable` | no invocation observed at all | no ranking possible |

A `## Skill telemetry coverage` table reports per-runtime evidence records and
whether invocations are observable there.

**Review resolutions (all applied).**

- `holistic-unknown-runtime-overclaim` (important) — the coverage table asserted
  that `unknown` activity has no model and cannot invoke skills. `runtime_name()`
  returns `unknown` whenever env markers are absent, so it means *unattributed*.
  Confirmed against the live vault: 1212 of 1816 records are `unknown`, including
  `agent-run`, `review-round`, `surface-lifecycle`. The claim was false for the
  majority of records, and excluding `unknown` from uncovered runtimes could still
  print "complete verdict" — the exact overclaim RT06 removes. The row is now
  `unattributed / unknown — runtime not recorded`, and an unattributed record
  carrying an `AGENT_DRIVEN_OPS` op counts as uncovered and blocks the verdict.
- `holistic-router-hint-in-use-overclaim` — "in use — do not remove" contradicted
  the same report three sections earlier. Now "unverified — a prompt match, not an
  invocation; do not treat as removable"; docstring and docs aligned.
- `holistic-records-observed-units` — column renamed to `Evidence records`; the
  paragraph states the counts are a presence test, not comparable across runtimes.
- `holistic-router-runtime-not-normalized` — both seams clamp through one
  `normalize_runtime()` helper.
- `holistic-empty-window-message` — the branch now splits on observed Claude
  records and only suggests a source-coverage check when none exist.

**Files.** `scripts/pipeline-stats.py`, `tests/test_pipeline_stats.py` (new),
`Makefile` (`test-pipeline-stats`, wired into `test`), `docs/pipeline-observability.md`,
`docs/runtime-capabilities.md`, `skills/wiki-lint/SKILL.md`.

**Regressions.** 37 assertions in `tests/test_pipeline_stats.py`: classifier units
(Codex rescue, Claude-only hint does not rescue, unattributed-agent uncovered,
unattributed-without-agent-op still covered, tag clamping, complete verdict) plus
five end-to-end renders against a throwaway vault root with an isolated `HOME` —
Codex-active, Claude-only, unattributed-orchestration, evidence-free, and
healthy-but-empty. Red-then-green observed for both product gaps and for the
review findings.

**Verification.** Configured `scoped` profile: `make test-harness` ✅,
`make test-model-routing` ✅, `git diff --check` ✅. Affected suites re-run after
the review commit: `test-pipeline-stats`, `test-pipeline-events`,
`test-claude-subscription`, `test-skill-budget`, `test-instruction-lint`,
`test-improve-skills`, `test-router` — all pass. Driven against a copy of the real
live event log: the false 32/32 verdict is gone, Codex and unattributed activity
both surface as boundaries, and the empty-window message no longer blames healthy
