# 2.5 real dogfood RT07 stale identity diagnostic

## Outcome

Added `upgrade-preflight.py --diagnose-identities`, a read-only JSON diagnostic that reuses the existing preflight classifier and operation ledger. It reports exact operation/worktree pairs as `active`, `proven-stale`, `ambiguous`, or `mismatched`, with identity-bound guidance. Only a self-owned, path-exact, terminal dispatch with settled effects and zero owned resources can prove its same-ID/same-path v3 worktree mirror stale. The command never edits state, chooses an owner, deletes a resource, or runs a recovery command.

- `18de878` adds the shared classifier, CLI mode, and deterministic four-state regressions.
- `c4996d4` documents classification, exit, and inspect-before-remove semantics.

- `a3ee3c5` applies every holistic review finding: missing and unmatched identities now emit evidence-only guidance without derived owners; a missing worktree path cannot emit a Git command; active cancel and matched-operation fields are documented; and regressions cover both new branches plus byte-for-byte immutability of every diagnostic input, including the operation record.
